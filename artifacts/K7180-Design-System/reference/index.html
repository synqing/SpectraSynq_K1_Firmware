K718 REMOTED · HALO

Circular Design Language · Component Gallery · v0.1

The radial operating grammar for the K718 Remoted — a physical encoder with a round 480×480 display that helps a user see, understand, and shape music in real time. Every dial below is produced by one token-driven renderer (halo.js) — not hand-drawn. That is the discipline: variation lives only in Theme Territory, never in new dials.

Foundations

Color — meaning before mood

Semantic accents have fixed meaning across every theme (green is always confirm; red is always alert). Theme Territories restyle the palette, never the meaning. Contrast ratios are the board-documented targets on the dark background.

Structure

The Radial Grid — placement by band × zone

A circular display has no columns. HALO places every element by radius band (distance from center) and angular zone (clock position). Importance is centrality: the sacred Readout sits dead-center; navigation lives at the rim. Dashed cyan = bezel-safe radius (6%); coloured arcs = thumb-occlusion zones. The state model — rationalized (R1)

The boards tangled three different things. HALO separates them into orthogonal concerns: an Attention ramp (how much is revealed) × a Trust lifecycle (pending→committed) × an Alert overlay (interrupt). Any screen is a point in (Attention × Trust).

Variation · everything on the table

One grammar, six theme directions

No theme is married (Captain 2026-06-29). The same locked composition — hero = real enabled mode TEMPO_RIVER_WALK, type = DIN Condensed + Inter — rendered across six directions spanning the design space: austere↔vivid, dark↔light, cool↔warm. This is theme-only variation (swap a token set, never draw a new dial) — the antidote to variant-dial churn. Default reference = the most austere (Measurement Grade), per the craft audit; loud themes are sanctioned variation, not the reference. None canonical until you choose.

Application · verified against firmware

Modes & readout — the Honesty Ledger

Honesty Rule H-1: the dashboard must never display a control or value the firmware cannot provide. Every element is tagged from a firmware audit (DLG-01, file-cited). A shippable screen contains only BACKED. ASPIRATIONAL ◇ is roadmap, never live truth.

Governance

What is locked, open, forbidden

Locked

  • radial grid & ring roles
  • gesture & state model
  • component set
  • legibility ladder
  • the six principles

Open (sanctioned)

  • Theme Territory only
  • palette · motion · density
  • new Territories may be proposed

Forbidden

  • new decorative dials
  • per-screen collars
  • burying key info
  • simultaneous-data overload
  • legibility traded for style

The governance test (apply before any change)

Does this compose existing named HALO elements within the locked grammar, varying only Theme Territory? Yes → in grammar, proceed. Invents a new layout/dial? No → out of grammar, STOP. (This is the churn the freeze was meant to end.)
