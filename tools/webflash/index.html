How to flash

  • Normal flow: plug the K1 in over USB, click Connect, pick the port. The S3's native USB usually drops into the bootloader automatically.
  • ROM mode: if sync fails, hold BOOT, tap RESET, release BOOT — the flasher retries for 20 seconds.
  • Close serial hogs: quit pio device monitor or anything else holding the port.
  • After flashing: the board resets itself; press RESET if it doesn't.

    • What happens

    esptool-js enters the ROM stub, raises the baud rate, then writes each image at the offset recorded in manifest.json — bootloader, partition table, OTA data seed and app. Flash header parameters are kept exactly as built (keep).

    Prefer the CLI?

    The same images live in firmware/<env>/ — flash with pio run -e <env> -t upload from the repo (which also enforces the device-identity guard), or with plain esptool at the manifest offsets.

    Browser support

    Chrome or Edge on desktop, over HTTPS or localhost. Web Serial is required — other browsers will show a warning here.
