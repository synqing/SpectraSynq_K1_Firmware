# IM69D130 vs Main-K1 — bench evaluation, 2026-08-05

**Devices:** bench `B489A500` (`k1_bench_im69d`) and main `F887A500` (`k1_hardware`), captured
**simultaneously** in one room off one loudspeaker.
**Published sheet:** https://claude.ai/code/artifact/4853d2c4-3cfe-406e-b620-45f7c09a14c6
> **SUPERSEDED 2026-08-10:** IM73D122 is **deprecated**. Binding authority:
> [`CAPTAIN_CORRECTION_2026-08-10_unit2_im69d_im73d_deprecated.md`](./CAPTAIN_CORRECTION_2026-08-10_unit2_im69d_im73d_deprecated.md).
> The historical line below is retained as archive only.

**Production decision (ARCHIVE — superseded):** UNCHANGED. IM73D122 remains the production mic. Nothing here reopens that.

## 1. Verdict

| Question | Answer |
|---|---|
| Is the IM69D130 a better microphone than the IM73D122? | **Yes, in the raw domain** — lower noise floor, 2.3–3.5× the dynamic range. |
| Is it better than the Main-K1 as currently configured? | **Not as it stands.** It never reports silence, so the lamp never goes dark. |
| Is that a microphone problem? | **No.** It is gain + threshold. The part itself is the quietest of the three. |
| Is the loudness/AOP advantage proven? | **No — not tested.** See §5. |

## 2. Raw-domain comparison (the only admissible mic-vs-mic reading)

`raw_i16_*` is pre-gain, pre-DC, pre-loud-guard — the comparator required by
`im73d-audio-pipeline-purity-audit-2026-07-06.md`. Both PDM mics emit it; both ran DSR_16S on the
same bench unit with the same track and volumes.

| | IM73D122 (2026-07-06) | IM69D130 (2026-08-05) |
|---|---|---|
| Quiet `raw_i16_rms` | 34.0 | **12.8** |
| Quiet `raw_i16_abs_peak` | 59.0 | **21.5** |
| Music `raw_i16_rms` p90 @ 45/60/75 | 48.3 / 94.2 / 160.8 | 41.8 / 119.7 / 209.2 |
| Music over own floor | 1.4× / 2.8× / 4.7× | **3.3× / 9.3× / 16.3×** |
| `raw_i16_near_pct` | 0.0 | 0.0 |

The IM69D130's part number implies a *worse* noise figure (69 dB SNR vs 73), so this result was the
one least expected and is the most worth re-confirming. **Caveat:** the IM73D legs are a month older,
so room and background differ. Effect sizes of 2.3–3.5× are unlikely to be entirely date.

## 3. The open defect — never goes dark

Quiet room, music off, both devices simultaneously:

| | Main-K1 (SPH0645) | Bench (IM69D130, gain 16) |
|---|---|---|
| Learned `SSL` | 602 | 253 |
| Quiet `max_raw` p90 (two legs) | 411 · 279 | 1190 · 307 |
| `peak_scaled` | 0.00 · 0.01 | 0.76 · 0.31 |
| `silence` flag | 100% · 100% | **0% · 0%** |
| Beat `lock` | 0% · 0% | **33% · 31%** |

The lamp lights when `max_raw` rises above `SSL`. On the bench that is true *in silence*, so the
output glows and the tempo tracker locks onto room noise. Even the quieter of the two legs (307)
clears 253 — this is not one noisy moment.

**Why calibration cannot rescue it at this gain:** the learn window is
`NOISE_CAL_SSL_MIN_VALID_RAW 50` … `NOISE_CAL_SSL_MAX_VALID_RAW 720` (`system/constants.h:33-34`).
A quiet band reaching 1190 needs a threshold outside that window, which the firmware will reject.

## 4. Recommended next step

Halve `K1_MIC_IM69D_INPUT_GAIN` from `16.0f` to `8.0f` (`system/constants.h`, under
`#ifdef K1_MIC_IM69D_PDM_V1`), then request a Captain silence-go and re-calibrate.

| | at gain 16 (measured) | at gain 8 (projected) |
|---|---|---|
| Quiet `max_raw` | 307 – 1190 — **overflows** the `[50,720]` window | 154 – 595 — **fits** |
| Music `max_raw` @ 45/60/75 | 3 400 / 9 800 / 17 300 | ≈1 700 / 4 900 / 8 600 |

Music stays far above threshold and further from the 30000 near-rail. The gain-8 column is arithmetic
on this session's measurements, **not a second measurement** — it needs one confirming capture.

The same sensitivity that causes the silence failure is a genuine advantage on quiet material: at the
lowest music level the IM69D130 locked 97–100% of frames (conf 0.90–0.92) against the Main-K1's
44–67% (conf 0.54–0.76). By vol 75 both are locked.

## 5. What this does NOT establish

- **The AOP / loudness advantage is untested.** Neither mic came within 1% of its rail. The ladder was
  stopped at Captain's instruction, and the output transducer was a **Bluetooth Bose Mini II
  SoundLink**, whose own limiter would compress before either microphone did. Testing this needs a
  different loudspeaker, not a higher volume setting.
- **Against the Main-K1 only shape and outcomes are admissible.** The SPH0645 build emits **no**
  `raw_i16_*` at all — that block compiles only under the PDM mic flags (`audio/i2s_audio.h:873-881`).
  So no absolute mic comparison against the Main-K1 is possible without a firmware change.
- **The two devices ran different firmware trees** (`main 1c131a9` vs lane `3b59794`) with different
  `[AP]` schemas — a second reason cross-device absolute numbers are not used above.
- **Mic B (RIGHT slot) was never exercised**, so Stage 1b and the stereo work (Stage 2) remain open.
- One vol-75 repeat is excluded: the capture process was killed mid-leg and the bench recorded no
  frames.

## 6. Reproduce

```bash
# capture (both devices at once; roles are mutually exclusive per fitted mic)
python3 scripts/regression-harness/im73d_audio_eval.py \
  --roles bench_im69d,main_sph \
  --require-build-env "bench_im69d=k1_bench_im69d,main_sph=k1_hardware" \
  --track <track> --start-offset 35 --duration 30 \
  --volumes 45,60,75 --repeats 2 --quiet-repeats 2 \
  --output-dir _scratch/im69d_vs_main_20260805

# if a run is interrupted before it writes summary.json
python3 scripts/regression-harness/recover_eval_summary.py --run-dir <run> --duration 30

# comparison, tiered by what each claim survives
python3 scripts/regression-harness/mic_ab_compare.py \
  --left-summary  artifacts/im73d_dsr_audio_eval_2026-07-06/20260706T180529_dsr16_controlled_audio/summary.json \
  --left-role bench_im73d --left-label "IM73D122 DSR16" \
  --right-summary _scratch/im69d_vs_main_20260805/<run>/summary.json \
  --right-role bench_im69d --right-label "IM69D130 DSR16"
```

`mic_ab_compare.py` refuses to present an absolute comparison when one side lacks `raw_i16_*`, and
carries a source-limiter detector: if both devices' normalised level curves flatten together, the
loudspeaker compressed and no microphone headroom conclusion is drawn.
