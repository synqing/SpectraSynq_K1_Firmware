1. The sentence that must stay true

After the show is painted and incandescent-mixed, and before the 48-bit pack, Core 1 applies exactly one look from a 16-slot table. Slot 0 returns the input. Changing the slot never requires a rebuild. Palettes stay the paint. Looks stay the print.

Tonight’s inverse-gamma is not a library. It is one generated curve compiled as destiny. This design turns it into :look=1 and makes last night :look=0.

Slots 0–7 compiled. Slots 8–15 loadable. Slot 0 cannot be overwritten. CRC fail keeps the previous look. LittleFS path /look/NN.klut, open only on the serial/loop core (existing heap-precondition law).
