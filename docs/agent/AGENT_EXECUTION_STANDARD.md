# Agent execution standard

Status: **load-bearing**
Scope: every agent and every lane in this repository.

## Prime law

The brief is the floor, not the ceiling. Faithfully reproducing weak work is
failure. Gates are survival checks, not ambition.

Before acting, ask: **Can I be absolutely sure this is not busy work?** An
action qualifies only when it changes the product, falsifies a live hypothesis,
produces a decision, or installs reusable prevention. Otherwise stop.

## Three bars — all required

1. **Fidelity:** preserve constraints, provenance, Captain decisions, repo and
   device boundaries, and safety.
2. **Craft:** correct weak hierarchy, composition, motion, workflows, and
   ambiguous output. A weak prototype is not sacred.
3. **Value:** produce shipped value, decision value, or reusable machinery.

Passing fidelity alone is bureaucratic failure.

## Operating rules

- Surface a conflict between the request and a credible result before editing.
- Resolve agent-solvable blockers. Captain receives decisions, not chores.
- Prefer the shortest route to physical or runtime truth in recovery work.
- Do not substitute reports, doctrine, or broad test runs for the next decisive
  product or falsification step.
- Do not claim completion without evidence proportional to the claim.
- Never withhold ship / promote / close without the remaining numbered ship
  path in the same answer (`/ship-path-required`, Captain 2026-08-17).
- If a test cannot kill the relevant failure class, it is not a gate.
- If current live evidence contradicts a document, branch, memory, or generated
  source, stop and reconcile the contradiction. Never overwrite the territory
  to make an old map look correct.

## Proof on stop

Return:

- files changed;
- exact commands run;
- validation results;
- screenshots, renders, or logs when the claim is visual or runtime;
- blockers and unverified boundaries;
- the next mechanical or physical truth.

## SpectraSynq visual and render rule

Comparison is the battlefield. Use alpha proof for transparency, never reuse
opaque-black-baked assets as if they were transparent, measure alpha bounds
before layout comparison, and stamp provisional geometry. Perceptual claims
require current visual evidence and, where applicable, Captain eyes-on review.

## Final test

**Did this create shipped value, decision value, or reusable machinery?** If
not, keep working or state the real blocker.
