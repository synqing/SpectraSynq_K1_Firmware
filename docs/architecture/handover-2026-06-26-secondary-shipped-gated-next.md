## 4 · LOAD-BEARING LESSONS this session (each cost or saved a real failure)
1. **Mutation-anchor guard** (the Captain-requested permanent fix). The 2026-06-25 preset defect = a dispatcher COMMENT carrying the literal `strcmp(command_type, "preset")` stole the `count=1` mutation rglob → a silently-blind tooth (Gate Fα catches `count==0` but NOT `count>=2`). 2. **ORACLE-LINK for the COMPILE-based replay oracle.** The replay oracle host-compiles `serial_cmd_handlers.cpp` as a STANDALONE TU (in `MODULE_CPPS`). A lifted handler may use a host facility that TU never saw before — `secondary_palette_index`'s `strcpy_P`/`pgm_read_ptr` (device: real pgmspace; firmware green) were defined only in the driver's `serial_replay_host_stubs.h`. Fix: **promote shared host shims to the shared stub `Arduino.h`** (`#ifndef`-guarded; driver copy no-ops). No firmware coupling to test stubs. (Companion to the prior `sb_queue_*` guaranteed-external-stub lesson.)
3. **A call-site-sever tooth for the COMPILE-based replay oracle MUST be compile-safe** — use a `false &&` short-circuit, NOT a `_SEVERED` rename. `harness_selftest._mutated_capture` only catches `TypeError`; a broken host build raises an uncaught `RuntimeError` that **crashes the selftest** instead of registering a clean catch. (The STRUCTURAL oracle is pure-parse, so its `_SEVERED` sever is fine there — don't confuse the two.)
4. **The structural gate sidesteps async-write modelling** (TRIZ #13/#22) — see §3. Don't build a fragile async replay model; it's a blind-lock surface.
5. **`FieldSnap[N]` array sizing** — the replay driver's snapshot arrays are fixed-size (`FieldSnap before[96], after[96]`). Adding globals can overflow; bump the size (was 64, now 96 at 65 fields).
6. **Merge model = MANUAL.** There is **no auto-merge automation** (only `.github/workflows/ci.yml`; `autoMergeRequest` null). The Captain merges PRs manually on CI-green. (An earlier handoff note falsely claimed "the repo auto-merges" — tombstoned.)
7. **Commit-message gotcha (zsh):** `git commit -m "... \`backtick\` ..."` triggers **command substitution** — backtick content is silently executed + stripped from the message. **Use `git commit -F -` with a heredoc** (or `-F <file>`) for any message containing backticks.
