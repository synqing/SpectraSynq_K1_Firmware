  • 1 · Now playing — mode name 56px Bebas, palette, FPS/BPM/LOCK. Answers "what is the lamp doing" at a glance.
  • 2 · Control deck — three 56px sliders, the actual work surface. Result ticks: ✓ applied / … pending.

Utility moves

  • Mode grid off-glass — 16 cramped 12px chips → 96px picker cards with IDs. Composer shows current mode + BROWSE.
  • LINK chip → popover — six diagnostics on tap, OPEN HEALTH for full page. No pill noise when healthy.
  • Result-backed acks — per-slider ✓/… makes K1 truth visible (SSA finding).
  • Hub rows preview live data — hub doubles as overview, not just a menu.
  • Anomaly highlight — health flags only out-of-threshold values (see lvgl_max).
