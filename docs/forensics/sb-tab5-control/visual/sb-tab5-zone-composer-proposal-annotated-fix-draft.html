Visible Hierarchy

  • Level 1: title, AP/WS status, centre-origin light field.
  • Level 2: selected surface and five active parameters.
  • Level 3: overview cards, Smart Director split and queue state.
  • Colour is semantic: cyan primary, green secondary, purple director, gold centre/status.

Type System

  • Bebas Neue: page titles and selected-surface headings.
  • Rajdhani: labels, action names and compact UI copy.
  • JetBrains Mono: numeric values, IDs, BPM, queue and IP readouts.

SB Boundary

  • No LightwaveOS donor pages are reachable from this mock.
  • No donor protocol startup traffic: no getStatus, zones.get, effects.list or palettes.list.
  • K1 remains AP-only; Tab5 joins the K1 AP and sends command intents over WS.
