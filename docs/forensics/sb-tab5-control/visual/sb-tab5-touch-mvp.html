Decision Options

Recommended: Native SB Touch MVP

  • Small AP-only WS facade inside SB.
  • Use fixed queue and current SB setters.
  • Fastest path to real Tab5-to-K1 proof.

Fallback: Host Bridge

  • Tab5 UI talks to a Mac-side serial proxy.
  • Useful for UX proof, not product architecture.
  • Avoids SB network risk temporarily.

Defer: firmware-v3 Parity

  • Ports effect metadata, zones, SynqMatrix, OTA, debug.
  • High integration and timing risk for SB.
  • Wrong first step for touch-only prototype.
