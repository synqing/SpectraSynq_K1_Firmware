# K1 L1 Accent A/B Captain Verdict

## Setup

- Main K1 `1101`: control, Smart Assist on, Smart switching on, Smart hooks off, EdgeMixer off.
- Bench K1 `1401`: candidate, Smart Assist on, Smart switching on, Smart hooks on, EdgeMixer on, complementary mode, strength `0.350`.
- Both K1s were noise-calibrated by Captain before this judgement.
- Music was playing during the judgement.

## Verdict

- `[FACT]` Captain reported: "for what we're testing for, L1 passes on the 1401".
- `[FACT]` This verdict applies to the L1 Accent scope: event accent / edge-interest layer, not full SynqMatrix-style autonomy, palette automation, speed modulation, or show sequencing.
- `[INFERENCE]` L1 Accent is approved as perceptually useful enough to keep and build upon.

## Boundary

This does not approve broader autonomy features. Palette changes, speed changes,
show-level mode sequencing, and deeper visual memory remain separate lanes.
