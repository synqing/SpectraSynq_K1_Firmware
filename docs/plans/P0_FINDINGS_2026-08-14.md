# P0 findings — the kill criterion fired

**Authorisation:** `CONDITIONAL_GO_P0_MEASUREMENT_ONLY`. No source mutation performed.
**Instrument:** `k1_bench_im69d_stereo` @ `623997c7`, epoch 1786716073, flash verified by
exit code + new epoch. Bench `B489A500` on `/dev/cu.usbmodem12401`.
**Witness:** MacBook Pro Microphone, resolved BY NAME.

## Verdict

> **REFUTED — "one IM69D capsule is dead or unpopulated".**
> Both decoded channels are alive, independent, and responsive.
> **The fault is in mono slot semantics, not in a dead part.**

Per Rev B T0.1b this is a stop-and-re-fork, not a result to reinterpret.

## The contradiction this exposes (the real lead)

The stereo capture disagrees with the mono measurements taken earlier the same day:

| build | quiet rms | response to music |
|---|---|---|
| `hpf` (mono, **default** slot) | 80–112 | **none** |
| `hpf_slotr` (mono, `SLOT_RIGHT`) | ~7 | responds |
| stereo array 0 ("L") | **7.86** | **+19.6 dB** |
| stereo array 1 ("R") | **117.6** | **+28.4 dB** |

Two facts follow:

1. **The stereo array labels are inverted relative to the mono `slot_mask` semantics.**
   Mono `SLOT_RIGHT` (~7) matches stereo array 0; the mono default (80–112) matches stereo
   array 1. This is the **documented IDF 5.4.1 inversion** already recorded for the SPH0645
   at `i2s_audio.h` ~L18-34 ("the slot semantic inverts when `ws_pol=true`"), now reappearing
   on the IM69D path.
2. **Array 1 responds strongly in stereo (+28.4 dB) while the mono default did not respond
   at all**, despite matching quiet floors. Same nominal source, opposite behaviour ⇒ the
   mono single-slot path is not delivering what the stereo path delivers. **That, not a dead
   capsule, is the defect to chase.**

## What is NOT established (do not infer)

- **Which physical capsule (IM1/IM2) maps to which decoded array.** Level order alone is not
  identity — a 15× difference could be capsule sensitivity, placement, or acoustic exposure.
- Why the mono single-slot path fails to respond while the stereo path succeeds.
- Whether Unit 2 (`0C54FC00`, pins 39/38) shares the defect. Contamination follows the
  device+config epoch, not the date.

## Outstanding — requires Captain (physical, T0.1b checks 3 & 4)

1. **Directed near-field stimulus** at the IM1 position, then at the IM2 position.
2. **Acoustic occlusion** of each capsule position in turn.

Both are needed to convert "two independent signals" into "array *n* is physically capsule
*m*". Until then the slot↔capsule mapping is unproven and **G1 cannot be answered**.
