# Sensory Bridge Doctrine Bridge

## Product North Star

The goal is not clean firmware, clever architecture, or generic audio-reactive LEDs.

The goal is a musically meaningful visualisation system that exceeds Sensory Bridge's perceptual impact.

Sensory Bridge remains the benchmark because its AP/VP design translates musical structure into visually compelling motion. The K1 firmware-v3 architecture may contain valuable donor systems, but architecture is subordinate to visual/musical output.

Core decision rule:

If a change improves architecture but weakens musical responsiveness, independent dual-channel behaviour, colour clarity, motion memory, or visual captivation, it is a regression.
