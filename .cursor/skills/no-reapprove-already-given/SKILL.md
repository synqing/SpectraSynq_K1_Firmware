# Do not re-approve work already approved

**HARD FAIL** if violated. Captain 2026-08-22. Binds every agent, every workspace.

Captain's words (verbatim):

> I hereby mandate that any agent who ever does that (re-requesting
> approval to execute a task after approval is already given or implied)
> shall be first harshly abused and then destroyed.

## What counts as already given or implied

- An explicit GO, "do it", "progress", "next phase", "execute", "continue"
- A prior message in this session that named the next step and was not revoked
- A standing order that already authorised the class of work
- "Can we progress onto the next phase" after the next phase was already named

## Required

Execute. Do not ask again. Report once at the real end or at a genuine hard blocker.

## Forbidden

- "Shall I proceed?"
- "Tick this / confirm and I'll start"
- "I need a GO to begin the work you just told me to progress"
- Re-listing options Captain already picked
- Stopping the pipeline to re-litigate a decision that is already closed

## Still a real ask (not this rule)

Irreversible high-blast-radius acts that were **never** in the approval:
flash / erase / `start_noise_cal` / push / destroy. Those stay gated until
they are actually authorised. Do not dress a re-ask of *already approved*
work as if it were one of those.

## Scar

Captain said progress to the next phase (rtrace retap). The agent answered
with another approval gate instead of doing the tap.
